# 气泵扫频与追频算法详解

---

## 1. 基于最大功率的算法

### **1.1 核心原理**

通过监测气泵的直流功耗，**寻找功率最大点**作为最优工作频率，从而实现效率最优控制。

### **1.2 扫频阶段**

1.  **频率扫描**：在设定的频率范围内，以 `100Hz` 为步进进行扫描。
2.  **功率记录**：在每个频率点，通过电压闭环控制算法保持目标电压，并记录对应的功率值。
3.  **最优频率确定**：比较所有记录的功率值，将**最大功率对应的频率**设为初始工作频率，并保存该最大功率值。

### **1.3 追频阶段**

*   **常温追频**

    1.  **功率监控**：周期性地比较当前功率与已记录的最大功率。
    2.  **智能调整**：当功率差值超过预设阈值时，采用**三点比较法**（当前频率 `±20Hz`）来寻找新的最大功率点，并更新工作频率。

*   **高温追频**

    1.  **高温触发**：当功率差值**持续高于**高温阈值时，自动触发小范围的精细扫频。
    2.  **参数优化**：同时，**缩短追频周期**并**减小功率比较阈值**，以适应高温环境下的工作特性。
    3.  **自动恢复**：若功率差值在一段时间内能稳定在阈值以下，系统将自动切换回**常温追频模式**。

## 2. 基于相位差的算法 `(暂未使用)`

### **2.1 核心原理**

通过检测驱动电压与电流之间的相位差，**寻找相位差最大点**对应的频率作为最优工作频率。

### **2.2 实现方法**

*   **FFT 相位差算法**
    1.  **数据采样**: 采集 `128` 个点的电压和电流数据。
    2.  **FFT 计算**: 对电压和电流数据分别进行 `FFT` 变换，计算出各自的相位。
    3.  **相位差计算**: 电压相位减去电流相位，得到最终相位差。

*   **点积相位差算法**
    1.  **波形截取**: 采样 `128` 个点的数据，并通过过零点检测截取一个完整的波形周期。
    2.  **参数计算**: 计算周期内电压和电流的点积以及各自的均方根值 `(RMS)`。
    3.  **相位差计算**: 使用**反余弦函数** `acos` 计算相位差，并进行采样延迟补偿。

*   **过零比较器相位差算法**
    1.  **偏置设置**: 计算电压和电流的直流偏置，并将其设置为硬件比较器的参考电压。
    2.  **时间差测量**: 利用定时器的**输入捕获**功能，精确测量电压和电流信号过零点之间的时间差。
    3.  **相位差转换**: 将测量到的时间差转换为相位差。

### **2.3 扫频与追频**

*   **扫频阶段**：在宽频率范围内测量每个点的相位差，找到**相位差最大**的频率作为初始工作频率。
*   **追频阶段**：采用**扰动观察法**，在当前工作频率上施加微小扰动 `(±20Hz)`，根据相位差的变化趋势来调整频率，从而实时追踪最优工作点。

## 3. 基于最小阻抗的算法 `(暂未使用)`

### **3.1 核心原理**

通过检测气泵的阻抗 `(Z=V/I)`，**寻找阻抗最小点**对应的频率作为最优工作频率。

### **3.2 扫频与追频**

*   **扫频阶段**：在宽频率范围内测量每个点的阻抗值，找到**阻抗最小**的频率作为初始工作频率。
*   **追频阶段**：同样采用**扰动观察法**，在当前工作频率上施加微小扰动 `(±20Hz)`，根据阻抗的变化趋势来调整频率，以实时追踪最优工作点。
